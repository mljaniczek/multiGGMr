# Print a multiggm_platform_fit object

Displays a concise summary of a fitted multi-platform multi-GGM model.

## Usage

``` r
# S3 method for class 'multiggm_platform_fit'
print(x, ...)
```

## Arguments

- x:

  A `multiggm_platform_fit` object returned by
  [`multiggm_mcmc`](https://mljaniczek.github.io/multiGGMr/reference/multiggm_mcmc.md)
  with `method = "ssvs_platform"`.

- ...:

  Ignored.

## Value

Invisible `x`.
