# Print a multiggm_fit_list object

Displays a concise summary of a multi-chain multi-GGM fit.

## Usage

``` r
# S3 method for class 'multiggm_fit_list'
print(x, ...)
```

## Arguments

- x:

  A `multiggm_fit_list` object returned by
  [`multiggm_mcmc`](https://mljaniczek.github.io/multiGGMr/reference/multiggm_mcmc.md)
  with `nchains > 1`.

- ...:

  Ignored.

## Value

Invisible `x`.
